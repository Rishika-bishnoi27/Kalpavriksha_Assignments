# Assignment 1
This assignment is based on C programming and expression evaluation.

## About
The program takes an arithmetic expression as input and evaluates it using the required order of operations.
It also checks for invalid expressions and division by zero.

## Operations Used
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## Concepts Used
- C Programming
- Variables
- Operators
- Conditional Statements
- Loops
- Input and Output
- Character Handling

## Error Handling
The program shows an error message for:
- Invalid expressions
- Division by zero
- Expression ending with an operator
- Operator appearing before a number
- Invalid characters

## How to Run
Compile the program using GCC:
```bash
gcc calculator.c -o calculator
```

Run the program:
```bash
./calculator
```

## Example
Input:
```text
3 + 5 * 2
```

Output:
```text
13
```
